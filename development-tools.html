Developer documentation

Development Tools

Prepare your Mac to build ConcordUI applications for Apple, Android, or both.

Start with the tools for your chosen platform. The current ConcordUI CLI workflow runs on macOS.

Apple SetupAndroid Setup

Start with Homebrew and ConcordUI

Install Homebrew and finish the installer’s shell setup. Then follow Install the CLI.

Use this command during setup to identify missing development tools:

concordui doctor

Apple: iOS and macOS

1. Install Xcode

Get Xcode from the Mac App Store

Open Xcode, complete its initial setup, and install the platform components you need. Choose a version compatible with your Mac.

Xcode overview · Compatibility and SDKs · Apple developer downloads

2. Select command-line tools

In Xcode, open Settings → Locations and select the installed Xcode version under Command Line Tools. Verify in Terminal:

xcode-select -p
xcodebuild -version
xcrun swift --version

Use the full Xcode installation for generating and building Apple projects.

3. Install XcodeGen

ConcordUI uses XcodeGen to generate its Xcode projects:

brew install xcodegen
xcodegen --version

XcodeGen documentation →

4. Choose a run destination

Start with your Mac or an iOS simulator. Install a simulator runtime through Xcode’s platform components if needed. For a connected device, configure your signing team and follow Xcode’s device setup instructions.

Apple’s simulator and device guide →

concordui doctor

Continue with Your First App: Apple.

Android

1. Install Android Studio

Download Android Studio

Choose the download for your Mac’s processor, install Android Studio, and complete the Setup Wizard.

Official installation guide and system requirements →

2. Install SDK components

Open Android Studio’s SDK Manager. Install the SDK platform and build tools required by your generated project, plus Platform-Tools (adb), Command-line Tools, Android Emulator, and an appropriate emulator system image.

Record the SDK location shown in SDK Manager. Use Google’s setup guidance if your command-line environment cannot locate the SDK.

SDK Manager · Environment variables · Platform-Tools and adb

3. Install the NDK and native build tools

In SDK Manager’s SDK Tools tab, enable Show Package Details and select the required NDK (Side by side) version. The ConcordUI release demonstration uses 29.0.14206865; follow your generated project’s requirements if they differ.

Install the CMake version required by the project. Follow the native-build documentation for CMake and Ninja setup.

Official NDK and CMake installation guide →

4. Install Swift for Android

Shared Swift code needs a Swift toolchain and an Android Swift SDK in addition to Android Studio. Choose matching toolchain and SDK versions supported by your ConcordUI setup.

  • Install Swift on macOS
  • Official Swift SDK for Android getting-started guide
  • Swift Android SDK project used in the ConcordUI demonstration

Follow the selected SDK’s installation and NDK configuration instructions, then check your active compiler and SDKs:

which swift
swift --version
swift sdk list

If several Swift toolchains are installed, ensure these commands select the one intended for Android builds.

5. Configure Java and Gradle

Android Studio includes a Java runtime. Configure the Gradle JDK to match the generated project’s requirements. Terminal builds also need compatible Java available in their environment. Use the generated project’s Gradle Wrapper for its expected Gradle version.

Java and Gradle JDK setup · Gradle Wrapper documentation

6. Prepare an emulator or device

Create an Android virtual device in Android Studio’s Device Manager, using a system image suitable for your Mac’s processor. Alternatively, connect an Android device and enable USB debugging.

Virtual device setup · Connected device setup

concordui doctor

Continue with Your First App: Android.

Check your app’s setup

After creating your app, run concordui doctor from its project root for project-specific checks. Resolve findings for your selected platform before generating its native project.

Use the official links for current installation details, and your ConcordUI project’s requirements for version choices.
