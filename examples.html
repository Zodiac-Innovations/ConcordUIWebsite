Run a sample application

First, follow Development Tools and Install the CLI for your chosen platform.

1. Download the examples

git clone https://github.com/Zodiac-Innovations/ConcordUIExamples.git
cd ConcordUIExamples/HelloConcordUI

Replace HelloConcordUI with ElementShowcase, FeaturesShowcase, PlatformShowcase, or PresentationShowcase to explore another sample.

Alternatively, use GitHub’s Code → Download ZIP, unzip it, and open Terminal in the selected sample’s folder.

2. Check the sample

concordui info
concordui doctor

3. Open an existing platform project

The repository includes native projects. Open the selected platform:

concordui apple ide

In Xcode, choose a Mac, iOS simulator, or connected device, configure signing when needed, and build/run.

concordui android ide

In Android Studio, allow Gradle sync to finish, choose a compatible emulator or device, and build/run.

Regenerate a platform project when needed

To regenerate from the sample’s shared source and configuration:

concordui apple create -d
concordui apple ide

Or, for Android:

concordui android create -d
concordui android ide

-d replaces the generated platform folder. It preserves Shared; commit any direct platform-project changes before regenerating. Follow Supported Platforms for deployment targets and compatible devices.
