Install the CLI

The ConcordUI command-line tool helps create and prepare your projects.

On this page
  1. Install Homebrew
  2. Install ConcordUI
  3. Check your environment
  4. Prepare your platform tools
  5. Update the CLI

1. Install Homebrew

The current ConcordUI CLI runs on macOS and is distributed through Homebrew.

If you do not already have Homebrew, visit the official Homebrew website and follow its installation instructions. Complete the installer’s “Next steps” so the brew command is available in Terminal.

Open Terminal and confirm Homebrew is ready:

brew --version

If you see command not found, finish Homebrew’s shell setup, open a new Terminal window, and try again.

2. Install the ConcordUI command-line tool

Add the Zodiac Innovations tap, then install ConcordUI:

brew tap zodiac-innovations/tap
brew install --HEAD concordui

The tap provides the ConcordUI package. --HEAD installs the version published on the CLI repository’s main branch.

Verify the installation and view the available commands:

concordui --version
concordui help

3. Check your development environment

Run:

concordui doctor

Review the results to see which development tools are available and which are missing. Prepare the tools for the platform you want to build first, then run doctor again.

Once you have created an app, run this same command from its project folder for project-specific checks.

4. Prepare the tools for your platform

The CLI creates platform projects that you build and run in Xcode or Android Studio.

Apple: iOS and macOS

  • Install Xcode, open it, and complete its initial setup.
  • Make sure Xcode’s command-line tools are installed and selected.
  • Install XcodeGen for generating the Xcode project:
brew install xcodegen

Use Xcode to select a Mac, iOS simulator, or connected device, then build and run.

Android

Install Android Studio and prepare the following tools used in the release demonstration:

  • Android SDK and platform tools, including adb
  • Android NDK 29.0.14206865
  • Swift for Android SDK
  • Java/JDK and Gradle
  • An Android emulator for running the first app

Use Android Studio’s SDK Manager to install Android SDK components. Follow the Swift Android SDK’s instructions for its toolchain setup, and use concordui doctor to check your environment.

Update the CLI

To fetch the latest published CLI:

brew update
brew upgrade --fetch-HEAD zodiac-innovations/tap/concordui
hash -r
concordui --version
concordui doctor

--fetch-HEAD checks the repository for updates to the installed HEAD package. hash -r refreshes your shell’s cached command locations.

If a command is not found

If brew is missing, revisit Homebrew’s setup instructions. If concordui is missing after installation, open a new Terminal window and check the installation:

brew list concordui
which concordui

For further help, visit the CLI repository.
