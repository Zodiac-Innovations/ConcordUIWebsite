Developer Release 1 · Swift · Native interfaces

Supported Platforms

ConcordUI targets native applications on iOS, macOS, and Android.

Shared Swift code describes your application’s content and behavior. Each platform implementation presents it with its native interface toolkit.

These values describe the framework declaration and current build configuration. They do not represent a complete test matrix for every OS release or device.

iOS

The public ConcordUI Swift package declares iOS 16 as its minimum. Build and run iOS applications using Xcode on a Mac, with an iOS simulator or connected device.

The current CLI’s Xcode project template still declares iOS 13. Set the generated app’s deployment target to iOS 16 or later to match the framework requirement.

Apple development tools →

macOS

The framework declares macOS 13 Ventura as its minimum, and the generated Apple project uses the same baseline. Use Xcode to build and run the native macOS application.

The development Mac must also meet the requirements of your installed Xcode version, which can be higher than the app’s runtime minimum.

Android

The generated Swift build defaults to aarch64-unknown-linux-android28 and packages native libraries for arm64-v8a. Use an ARM64 device or emulator running Android 9 / API 28 or later for the current default build path.

The Gradle template currently declares minSdk = 24 (Android 7), while the Swift build uses API 28. Android 7 and 8 compatibility is therefore not established by the current configuration; the Gradle setting alone is not a compatibility guarantee.

The project currently uses compileSdk = 36 and targetSdk = 36 (Android 16). These build settings do not mean the app requires Android 16 to run.

Android development tools → · Android versions and API levels

Development host

The current ConcordUI CLI workflow runs on macOS. Apple development uses Xcode and XcodeGen. Android development uses Android Studio, Android SDK/NDK tools, and a compatible Swift Android toolchain.
