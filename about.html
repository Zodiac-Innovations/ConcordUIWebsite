About ConcordUI

An open-source Swift framework from Zodiac Innovations.

ConcordUI brings shared application content and behavior to native user interfaces. It is created by Steve Sheets.

Apple interfaces use SwiftUI, and Android interfaces use Jetpack Compose. Current development focuses on iOS, macOS, and Android.
