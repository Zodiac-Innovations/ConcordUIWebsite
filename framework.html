The ConcordUI Framework

Explore the shared Swift framework, native platform implementations, and developer tools.

ConcordUI is open source. Developers can examine the code, understand how shared application content reaches each native platform, and contribute to the framework.

Main framework repository

The public ConcordUI repository is the main place to examine the framework used by applications.

Explore ConcordUI on GitHub

  • Core Swift package: shared protocols, components, and application model.
  • Apple implementation: native iOS and macOS interfaces through SwiftUI.
  • Android implementation: Swift support and Kotlin glue connecting to Jetpack Compose.

Understand the components · Supported platforms · Apache License 2.0

Command-line tool and source

The CLI prepares shared app projects, generates native projects, opens the IDEs, and checks development environments.

  • Published CLI repository and starter template
  • CLI source code in ConcordUIDevelopment

The CLI’s editable Swift implementation lives in the development repository. Access to that repository depends on its permissions.
