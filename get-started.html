Get Started

Go from a prepared Mac to your first native application using shared Swift code.

Start with Apple or Android, then add the other platform when you are ready. The current ConcordUI CLI workflow runs on macOS.

1. Prepare Your Tools →

Install Xcode for Apple, or Android Studio and the Swift Android toolchain for Android. Find official download links and setup checks.

2. Install the CLI →

Install Homebrew and ConcordUI, verify the command-line tool, and check your environment with doctor.

3. Create Your First App →

Initialize HelloApp, set its metadata and icon, generate a native project, and run it in your IDE.

4. Explore the Examples →

Explore working applications and feature showcases as you build your own app.

Choose your first platform

Apple: Prepare Xcode and XcodeGen, then follow the Apple steps to generate the project and run on your Mac, an iOS simulator, or a connected device.

Android: Prepare Android Studio, SDK/NDK tools, and the Swift Android SDK, then follow the Android steps to generate the project and run in an emulator or on a device.

Your app’s Swift code stays in Shared/Swift, its runtime resources in Shared/Files, and its icon sources in Shared/Icons.

Already have your tools installed?

Go directly to CLI installation, or to Your First App if ConcordUI is already installed.
