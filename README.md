# ConcordUI Website

Static developer website for https://concordui.org/, hosted by GitHub Pages.

## Pages

- index.html: product introduction and launch announcement
- get-started.html: onboarding overview
- installation.html: CLI installation
- first-app.html: first app walkthrough
- examples.html: sample applications (content to follow)
- docs.html: documentation overview
- guides.html: component tutorials
- reference.html: CLI and configuration reference
- about.html and updates.html: project information
- features.html, license.html, acknowledgement.html: existing reference pages

Shared responsive styling: assets/site.css. Pages contain their navigation directly so links work without JavaScript. Keep header and footer navigation consistent when editing pages. No build step required.
